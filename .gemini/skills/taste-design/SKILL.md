# Impeccable Design Taste Skill

This skill enforces high-end aesthetic standards for web applications, eliminating boring or plain UI designs.

## Principles of Impeccable Design

1. **Curated Color Palettes**:
   - Avoid standard default primary colors (plain `#ff0000` or `#0000ff`).
   - Use sophisticated HSL/Tailwind palettes: Dark Slate (`#0B0F17`, `#111827`), Emerald Glow (`#10B981`, `#059669`), Gold Accent (`#F59E0B`), Deep Indigo/Violet gradients.
   - Maintain proper contrast ratios while keeping subtle elegance.

2. **Depth & Elevation**:
   - Combine subtle 1px border highlights, drop-shadows, and background blurs to create layered visual hierarchy.
   - Example: `bg-slate-900/90 backdrop-blur-xl border border-slate-800/80 shadow-2xl shadow-emerald-950/20`.

3. **Student & Campus Focus**:
   - Clean, modern layout designed for mobile and desktop screens.
   - Live match cards, quick filters, fixture status tags (LIVE, FT, UPCOMING).
   - Dynamic match momentum charts, fan sentiment, campus rivalry badges.

4. **Typography & Layout Harmony**:
   - Strict spacing rhythm (`gap-2`, `gap-4`, `p-4`, `p-6`).
   - Crisp headings (`tracking-tight`, `font-extrabold`).
