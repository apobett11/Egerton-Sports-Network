# Playwright E2E & Automation Skill

This skill provides guidelines and tools for automated testing, screenshot visual validation, and user workflow verification using Playwright.

## Key Capabilities

1. **End-to-End Testing**:
   - Automated testing of user login, navigation, match score views, tab switching, and dashboard features.
2. **Visual Verification**:
   - Capture desktop and mobile viewport screenshots to verify UI alignment, theme changes, and responsiveness.
3. **Execution**:
   - Run tests with `npx playwright test`.
